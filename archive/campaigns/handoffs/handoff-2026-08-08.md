# Catch-Up research handoff — 2026-08-08

## Objective

The project began as an attempt to prove the Catch-Up draw conjecture via an \(N\mapsto N+4\) strategy transfer. It should now be treated as an unrestricted “solve by any means” effort:

- prove the conjectured outcome pattern;
- find a counterexample;
- prove useful structural reductions;
- or build formally sound certificate infrastructure that enables finite results to be checked in Lean.

No counterexample has been found.

## Formal game and semantics

The source formalization is CatchUpConjecture.lean (`SOURCE_CHECKOUT/FormalConjectures/Paper/CatchUpConjecture.lean`; historical path).

The semantics have been audited against the 2015 paper:

- Player 1’s opening consists of exactly one counter.
- On later turns, a player continues taking counters while strictly behind.
- Equality or overshooting ends the turn and switches players.
- If all remaining counters cannot close the deficit, the player receives them and loses; the formal evaluator’s immediate-loss shortcut is outcome-equivalent.
- The conjecture uses the positive interval `Finset.Icc 1 N`.

The local development already contains:

- the original absolute-score evaluator `valueAux`;
- normalized positions `(remaining, deficit)`;
- normalized one-pick evaluator `Position.value`;
- the proved equivalence `Position.value_eq_value_aux`;
- `GamePosition` with the player to move;
- `CanAvoidLoss`;
- `can_avoid_loss_iff_value`;
- post-opening decomposition of the root value;
- reachability and transition API;
- elementary `addFourCounters` API.

The current open conjecture states only the draw cases:
\[
T_N=\frac{N(N+1)}2\text{ even}\Longrightarrow
\operatorname{value}(\{1,\ldots,N\})=\mathrm{draw}.
\]

## Von Stengel’s recurrence and memory invariants

His evaluator is essentially the same normalized atomic recurrence already formalized locally.

Let \(S\) be the remaining counters and \(d=B-A\ge0\) the current player’s deficit.

For a selected counter \(i\in S\):

- if \(i<d\), the same player continues from \((S\setminus\{i\},d-i)\);
- if \(i\ge d\), players switch and the child deficit is \(i-d\), so the child value is negated.

Two additional invariants enabled his smaller implementation.

### Deficit bound

For a game on \(\{1,\ldots,N\}\), every reachable deficit satisfies
\[
d\le N.
\]

Continuing a turn decreases the deficit. Switching creates a new deficit equal to the overshoot from one counter, which cannot exceed \(N\).

### Parity invariant

Let \(T_N=N(N+1)/2\). At a position with accumulated scores \(A,B\), deficit \(d=B-A\), and remaining set \(S\),
\[
A+B+\sum_{i\in S}i=T_N
\]
and hence
\[
2A+d+\sum_{i\in S}i=T_N.
\]

Therefore
\[
d\equiv T_N-\sum_{i\in S}i\pmod2.
\]

Only half the deficit entries for each mask are reachable. When \(T_N\) is odd, reachable terminal outcomes cannot be draws, so one bit per entry suffices; when \(T_N\) is even, two bits suffice.

This explains the difference between von Stengel’s approximately 17 GB estimate for \(N=32\) and our approximately 72 GiB implementation.

## Structural theorem from the slides: uniqueness of a winning opening

Von Stengel gives a short proof that a winning interval game has a unique winning first move.

Suppose \(a<b\) were two winning openings from the tied root.

- After opening with \(a\), the opponent can select \(b\), catch up, and switch. This reaches remaining set \(S\setminus\{a,b\}\) with deficit \(b-a\), with the original player to move.
- After opening with \(b\), the opponent can select \(a\), remain behind, and continue. This reaches the same normalized pair \((S\setminus\{a,b\},b-a)\), but with the opponent still moving.

The assumption that both openings are winning forces the same normalized position to have contradictory values.

This appears to be the best small, bounded theorem to formalize next. The proof may generalize beyond interval sets, but the interval statement should be proved first.

## Stronger conjectured outcome pattern

The external computations suggest the following stronger conjectures.

### Draw cases

If \(N\equiv0\) or \(3\pmod4\), then the game is a draw. Moreover, for \(N\ge12\), every opening is drawing:
\[
\forall x\in\{1,\ldots,N\},\quad
\operatorname{value}(\operatorname{afterOpening}(N,x))=\mathrm{draw}.
\]

This is strictly stronger than the current root-value conjecture and may be a better induction target.

### Non-draw cases

For \(N\ge21\) with \(N\equiv1\) or \(2\pmod4\), Player 1 wins.

The conjectured unique winning opening is:

- \(2\) when \(N\equiv2\pmod4\);
- either \(1\) or \(3\) when \(N\equiv1\pmod4\).

The known exceptional losses are
\[
N\in\{9,10,14,18\}.
\]

The data do not yet give a simple rule deciding between openings \(1\) and \(3\) in the \(N\equiv1\pmod4\) cases: \(21,25,29\) use \(3\), while \(33,37\) use \(1\).

## Four-counter transfer status

The elementary position lift is
\[
(R,d)\longmapsto
(R\cup\{N+1,N+2,N+3,N+4\},d).
\]

A strong statewise value-preservation theorem is false.

Exact counterexamples:

- At \(N=11\), \((R=\{1,2,8\},d=11)\) is a draw, but adjoining \(12,13,14,15\) makes it a win.
- At \(N=12\), \((R=\{6,12\},d=6)\) is a draw, but adjoining \(13,14,15,16\) makes it a win.

These refute unrestricted statewise transfer. They do not refute:

- root-level \(N\mapsto N+4\) transfer;
- transfer restricted to reachable positions;
- transfer of `CanAvoidLoss` rather than exact values;
- a transfer relation that changes or couples deficits;
- a strategy simulation that uses the four new counters dynamically.

### Four-counter endgame classifier

The script catch_up_four.lean (`SOURCE_CHECKOUT/scripts/catch_up_four.lean`; historical path) suggests this symbolic value for the isolated block
\[
[N+1,N+2,N+3,N+4]
\]
at deficit \(d\), for \(N\ge4\):

```text
d = 0                 draw
d = 1                 loss
d = 2                 draw
d ≤ N+1               loss
d ≤ 2N+7              win
d = 2N+8              draw
d ≤ 3N+6              loss
d ≤ 4N+9              win
d = 4N+10             draw
otherwise             loss
```

It has been computationally validated over a large finite range but not proved parametrically. A proof could still be useful in a more sophisticated transfer argument.

## Strategy certificates

The local branch contains:

- exact Lean solver;
- one-sided strategy extraction;
- serialization-friendly strategy DAGs;
- an independent Boolean checker.

The checker is CertificateChecker.lean (`SOURCE_CHECKOUT/scripts/catch_up/CertificateChecker.lean`; historical path). Its central missing theorem is:

```lean
DAGValid dag →
  CatchUp.CanAvoidLoss dag.player
    (toGamePosition dag.gameSize dag.root)
```

followed by Boolean reflection:

```lean
checkCertificate dag = true →
  CatchUp.CanAvoidLoss ...
```

Without this soundness theorem, certificate acceptance is not yet a Lean proof.

For a certified root draw:

- Player 1 needs at least one opening from which Player 1 can avoid loss.
- Player 2 must be able to avoid loss after every Player 1 opening.
- Sharing subgraphs across multiple opening roots may be essential for compact certificates.

Full \(N=31,32\) tables should not be placed in Lean or run in CI. Only compact strategies or certificates would make those finite computations appropriate as formal tests.

## Recommended priorities

1. **Do not spend more time merely extending the exact frontier.**
   Exact results through \(N=38\) already exist, and the memory curve is severe.

2. **Formalize uniqueness of the winning opening.**
   This is a genuine structural theorem with a short known proof.

3. **Formalize the deficit bound and parity invariant.**
   These are reusable reachability facts and justify smaller verified evaluators.

4. **State the stronger conjectures in Lean**, subject to obtaining permission to cite the attached slides:
   - every opening draws in draw-capable games for \(N\ge12\);
   - the full win/draw/loss pattern for \(N\ge21\);
   - constraints on the unique winning opening.

5. **Study generalized positions `value[d][S]`.**
   Von Stengel explicitly identifies this as necessary. A proof of the root pattern probably requires invariants stronger than the root value alone.

6. **Continue \(N\mapsto N+4\) only with a weakened invariant.**
   Exact statewise equality is false. Promising alternatives are reachable-state simulation, `CanAvoidLoss` transfer, coupled deficits, or a relational invariant.

7. **Prove certificate-checker soundness** if verified computation remains part of the project.

8. **Ask von Stengel for his code and permission to cite or publish the slides.**
   His parity-packed representation and full table are useful reference material.

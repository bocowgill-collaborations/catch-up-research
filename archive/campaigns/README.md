# Earlier campaign archive

This archive preserves the August–September 2026 research that preceded the October collection. The [finding ledger](../../results/legacy-findings.md) gives 43 claim-level entries; the [notebook index](notebook-index.json) locates 263 chronological sections, including failed experiments and corrections. The [source manifest](../../verification/legacy-sources.json) records every inspected branch, commit, source version, original/exported hash, and disposition.

The import covers 15 local refs (14 Catch-Up branches and the counterexample-search checkout), 55 relevant commits, 236 unique paths and 290 distinct path/blob pairs. It adds 183 previously absent historical source versions/records, three research handoffs and one detailed run record. Existing mathematical sources and large generated payloads are not duplicated.

## Evidence and use

All content below is historical material outside the Lean build. Successful checks reported inside it refer to the original campaign. Old CHECK lines, commands and instructions are inert quotations of that context. A reviewer assessment is distinct from Lean verification. The current [verification guide](../../verification/README.md) defines what the collection builds.

Source variants, audit drivers and probe scripts are retained as `.txt` data when they are not currently supported programs. They may depend on the old project layout or omitted native certificate payloads. Consult their source IDs and hashes to reconstruct an original checkout; do not assume that renaming a file alone supplies its dependency closure. Current runnable small experiments remain in [computation/experiments](../../computation/experiments/).

Public exports normalize local paths and contact/account details. Markdown links into the old checkout are retained as historical path text. Original hashes are retained, and the export hash identifies the actual public version. Large-table counts and timings are recorded observations; no large search or new proof verification was run for this import.
